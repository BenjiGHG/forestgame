# Spotify iPad

Eine kleine native iPad-App, die die offizielle Spotify-Webversion in einer WKWebView öffnet.

## Auf dem iPad öffnen

1. Öffne den Ordner `SpotifyiPad` in **Swift Playgrounds**.
2. Starte das App-Projekt.
3. Die App lädt `https://open.spotify.com/`.
4. Anmelden und Spotify wie im Web nutzen.

## Enthalten

- iPad-optimierte Vollbild-Webansicht
- Zurück / Vorwärts
- Neu laden
- In Safari öffnen
- Ladeanzeige
- Spotify-Login bleibt in der WebView gespeichert

Hinweis: Das ist ein Web-Wrapper. Er ersetzt weder die offizielle Spotify-App noch verwendet er private Spotify-Schnittstellen.
